# WowderTour Bot — готовая версия

Сделано: каталог Кировска/Шерегеша/Вейка/Скейта, даты и цены, анкета заявки, SQLite CRM, карточки заявок, статусы, статистика и админка.

## Вставка в текущий проект
1. Сделай резервную копию текущей папки.
2. Замени содержимое файлов из этой сборки в проекте.
3. Свой `.env` НЕ заменяй: в нём должны быть `BOT_TOKEN` и `ADMIN_ID`.
4. Удали старый `wowder.db` только если хочешь начать CRM с нуля. Обычно НЕ удаляй.
5. `pip install -r requirements.txt`
6. `python bot.py`
7. В Telegram открой `/start`, для CRM — `/admin`.
